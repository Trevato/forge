# Live updates

- `.live-news` — the fixed, bottom-centred, click-through wrapper of the live-update markers: the quiet "N above" link (a §5 badge) and, in attn tone, the one word `offline` while the stream is down. There is no refresh bar: new rows are merged into lists in place (`.live-arrived` slides a row in for a reader at the top; scrolled or typing readers get the rows above with scroll compensated). The wrapper keeps it out of flow so showing it moves nothing, and the rule gives that badge a 36px target. A bare `.badge` cannot carry this: it is a small inline element that would insert itself into the content where the mount sits.
