# Talk build (#11010)

- `.talk-build`: the panel beside a building conversation: repository, preview, versions, Publish.
- `.talk-build-box`: the empty Talk's one box, "What do you want to build?", with its starters.
- `.talk-build-versions`: the numbered list of versions, newest first, the chosen one in bold.
- `.talk-build-starters`: the templates to start from, a plain link list under the box.
- `.talk-build-files`: the files a chosen version changed.
