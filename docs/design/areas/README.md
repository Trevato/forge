# Component areas

A new component class is named here, in a file for its area (`docs/design/areas/<area>.md`), in a code span
(`` `.my-class` ``) with a line on what it is for. The design check reads every file in this directory as §5 vocabulary,
so two pulls documenting different components touch different files and never conflict on `docs/DESIGN.md`.

Do not edit `docs/DESIGN.md` §5d: it only shrinks. Prefer a component §5 already has.
